## 10.0.0

### Major Changes

#### ✨ Новые компоненты для продвинутого UX

- **SidePanel** — Боковая панель, которая сдвигает контент страницы вместо наложения

  - Создаёт ощущение отдельной страницы/раздела
  - Идеально для детальных интерфейсов и больших форм
  - Поддержка хлебных крошек и навигации
  - Профессиональный UX для бизнес-приложений

- **BottomSheet** — Drawer снизу с поддержкой свайпа
  - Выезжает снизу вверх
  - Поддержка свайпа для закрытия
  - "Ручка" для свайпа (как на iOS)
  - Идеально для подтверждений и мобильных интерфейсов

### Breaking Changes

- Никаких breaking changes — компоненты полностью обратно совместимы

### Documentation

- Добавлена подробная документация для SidePanel и BottomSheet
- Добавлена сравнительная таблица Modal/Drawer/SidePanel/BottomSheet
- Добавлены примеры использования и рекомендации
